# Английский для работы и жизни

43 темы · 353 карточки · 359 записей Ryan · B1–B2.

Откройте опубликованную HTTPS-ссылку. При первом открытии приложение сохранит карточки и всё аудио — около 15 МБ. Дождитесь «Готово без интернета»; при ошибке нажмите «Повторить загрузку». После этого приложение и Ryan работают без сети, пока браузер сохраняет данные сайта.

На iPhone/iPad откройте ссылку в Safari: «Поделиться» → «На экран “Домой”». На компьютере/Android используйте установку приложения в меню поддерживающего браузера или кнопку «Установить».

Отметки сохраняются на этом устройстве. Чтобы перенести их с прежнего localhost, распакованного ZIP или другого устройства: «Мой прогресс» → экспорт; затем откройте опубликованную версию → импорт. Разные адреса не переносят прогресс автоматически. Safari и установленное приложение тоже могут хранить данные раздельно — при необходимости используйте экспорт/импорт.

При обновлении по прежнему адресу идентификаторы карточек и ключ хранения прогресса сохраняются. Когда появится «Обновить», можно применить новую версию; отметки не очищаются. Регулярный экспорт защищает прогресс, если браузер очистит данные сайта.

В эту папку включены только приложение, собственная иконка и учебное аудио. Исходных фото, OCR, служебных аудитов и секретов здесь нет. Для публикации GitHub Pages используйте содержимое этой папки как корень сайта; все адреса относительные. Service worker работает через HTTPS или localhost. Простое открытие index.html как файла позволяет пользоваться карточками и соседними аудиофайлами, но не устанавливает PWA.
